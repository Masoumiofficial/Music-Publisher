# سجاد موزیک پابلیشر

افزونهٔ مدیریت وردپرس برای ارسال تک‌آهنگ، ریمیکس، نوحه، موزیک ویدیو و آلبوم در سایت‌های دانلود موسیقی، به‌همراه هاست دانلود جداگانه.

**نسخه:** ۱.۰.۰  
**نیازمندی:** وردپرس ۶ و PHP ۷.۴  
**دامنه ترجمه:** `sajad-music-publisher`

## امکانات

- پنل جدا برای هر نوع محتوا
- آپلود یا لینک کاور، کیفیت ۱۲۸ و ۳۲۰، متن ترانه و عوامل اثر
- پیش‌نویس یا انتشار (انتشار نیاز به قابلیت `publish_posts` دارد)
- تنظیم آدرس‌های هاست دانلود و شناسه دسته‌ها
- کلید مشترک بین وردپرس و اسکریپت‌های `hostdl`
- رابط راست‌چین و ترجمهٔ فارسی

## نصب

۱. فایل `music-publisher.zip` را از مسیر افزونه‌ها بارگذاری کنید.  
۲. افزونه را فعال کنید.  
۳. از **پنل موزیک ← تنظیمات** آدرس‌ها، دامنه، دسته‌ها و کلید مشترک را وارد کنید.  
۴. پوشهٔ `hostdl` را روی هاست دانلود قرار دهید و `config.sample.php` را به `config.php` با همان کلید کپی کنید.

## استفاده

کاربر با قابلیت ویرایش نوشته فرم را پر می‌کند. افزونه یک نوشتهٔ معمولی می‌سازد و متای مورد انتظار قالب‌های دانلود آهنگ را ذخیره می‌کند.
