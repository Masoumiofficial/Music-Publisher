Admin console to publish movies, series seasons, trailers, and leech files for Persian video WordPress sites.

== Description ==

Film Series Publisher is a sister product of Sajad Music Publisher, specialized for movie/series download blogs.

Author and design: تیم توسعه اتحاد وردپرس — https://etehadwp.com

== Installation ==

1. Upload the film-publisher folder
2. Activate
3. Configure Film panel → Settings
4. Optional: deploy hostdl/ to the download server
