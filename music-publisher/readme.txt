Admin workflow to publish singles, remixes, nohe, music videos and albums for Persian music WordPress sites.

== Description ==

Sajad Music Publisher is an editorial console for Persian MP3 blogs. It creates standard posts and optional download-host jobs. It is not a public player or store.

== Installation ==

1. Upload the music-publisher folder to wp-content/plugins
2. Activate the plugin
3. Configure Music panel → Settings
4. Deploy hostdl/ to the download server with config.php secret
